# Assets Folder

## Logo Images

Place your Elevated Auto Detail logo images in this folder:

1. **elevated-logo-white.png** - White/light background mountain logo
2. **elevated-logo-badge.png** - Dark hexagon badge logo with blue accents
3. **elevated-logo-retro.png** - Retro 80s style sunset logo with truck

### How to Add Logos:
1. Save your logo images to this `/assets/images/` folder
2. The website will automatically use them once uploaded

### Brand Colors Used:
- Cyan Blue: #00D4FF
